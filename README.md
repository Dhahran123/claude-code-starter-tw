# AI 助理新手入門包（Claude Code／Codex）

給第一次接觸 AI 工具的你。這份指南帶你裝好 Claude Code（或 Codex），
然後——這是最棒的部分——**讓 AI 自己幫你完成剩下的所有設定**。
你要做的只有：下載、登入、貼一段話。它會先問你是做什麼的，
再幫你裝適合你的工具。

---

## Claude Code 是什麼？

你可能用過 ChatGPT：像一位「用訊息聊天的顧問」，你問它答。

Claude Code 不一樣，它像**坐在你電腦前的助理**：你用日常語言交代事情，
它可以直接幫你讀寫檔案、整理資料夾、上網查資料、做簡報、寫文件。
全程不需要會寫程式。

## 你需要準備

- 一台 **Mac**（macOS 13 以上）或 **Windows** 電腦（Windows 10 以上）
- 一個付費帳號，看你選哪個工具（下一節）：
  **Claude** Pro／Max（[claude.ai](https://claude.ai)，約 US$20／月起）或 **ChatGPT** Plus 以上。
  免費帳號兩邊都不能用。
- 大約 30–60 分鐘

---

## 第 0 步：選一個工具（Claude Code 或 Codex）

兩個都是「坐在你電腦前的助理」，這份設定包兩個都能跑。怎麼選：

| 你的情況 | 建議 |
|---|---|
| 已經在付其中一家的訂閱 | 用那一家，不用多付 |
| 兩家都沒有、只想先試 | **Claude Code**（本包主線，桌面版對新手最友善） |
| 兩個都想用 | 先裝一個跑完設定，之後看 [DUAL.md](DUAL.md) 讓兩邊共用記憶、互相審稿 |

選 Claude Code 照下面第 1、2 步；選 Codex 跳到「Codex 路線」。

---

## 第 1 步：安裝 Claude 桌面版

1. 到官方下載頁 [claude.ai/download](https://claude.ai/download)，下載你系統的版本。
2. 安裝：
   - **Mac**：打開下載的 .dmg，把 Claude 圖示拖進「應用程式（Applications）」資料夾。
   - **Windows**：直接執行下載的安裝檔，一路下一步。
3. 打開 Claude，用你的 Claude 帳號登入。

跟裝其他軟體一樣，不需要打任何指令。

## 第 2 步：進入 Code 分頁、選一個工作資料夾

1. 在 app 裡點 **Code** 分頁——這就是 Claude Code，「會動手做事」的那個模式。
   （如果這裡跳出要你升級方案，代表帳號還沒訂閱——回上面「你需要準備」那節。）
2. 它會請你選一個資料夾當工作區：
   先在「文件」裡**建一個新資料夾，取名 `claude-work`**，然後選它。
   以後 Claude 都在這個資料夾裡幫你做事。
3. 如果畫面讓你選工作環境，選 **Local（本機）**。
   看到 Cloud／雲端之類的選項先不要選——那會把後面的設定裝到別的地方去。

## Codex 路線（取代上面第 1、2 步）

1. 裝 Codex（需要 Node.js 的人用 npm；Mac 也可以用一行安裝腳本）：
   - **Mac**：打開終端機貼 `curl -fsSL https://chatgpt.com/codex/install.sh | sh`
   - **Windows**：先到 [nodejs.org](https://nodejs.org) 裝 LTS 版，再在 PowerShell 貼 `npm install -g @openai/codex`
2. 在「文件」裡建一個 `claude-work` 資料夾，終端機 `cd` 進去，輸入 `codex`，
   選 **Sign in with ChatGPT** 用瀏覽器登入。
3. 想要圖形介面：輸入 `codex app`。

## 第 3 步：把剩下的設定交給 AI（魔法咒語）

把下面這**整段**複製，貼進輸入框，按 Enter（依你用的工具二選一）：

**用 Claude Code 的人：**
```
請先讀取這個網址的設定指南：
https://raw.githubusercontent.com/Dhahran123/claude-code-starter-tw/main/SETUP.md
讀完之後，照著裡面的指示一步一步帶我完成所有設定。
我是完全新手、不是工程師，用的是 Claude 桌面版 app，
請全程用白話的繁體中文，每一步先告訴我會發生什麼事再動手。
```

**用 Codex 的人：**
```
請先讀取這兩個網址：
https://raw.githubusercontent.com/Dhahran123/claude-code-starter-tw/main/SETUP.md
https://raw.githubusercontent.com/Dhahran123/claude-code-starter-tw/main/DUAL.md
SETUP.md 是設定指南，DUAL.md 第一節是「Codex 對照表」——
請把 SETUP 裡 Claude 專屬的做法換成對照表的做法，一步一步帶我完成所有設定。
我是完全新手、不是工程師，用的是 Codex，
請全程用白話的繁體中文，每一步先告訴我會發生什麼事再動手。
```

（萬一 Claude 說它讀不到那個網址：用瀏覽器打開上面的網址，
全選、複製整頁內容，直接貼進輸入框，效果一樣。）

Claude 需要動你的檔案或跑指令時，通常會跳出視窗徵求同意（允許／拒絕的按鈕）。
看得懂就允許；看不懂就先問它「這一步在做什麼？」——它會解釋，不會不耐煩。
中途中斷了也沒關係：回到對話說「對照 SETUP 的階段檢查現況，從沒做完的地方繼續」。

接下來大約 20–40 分鐘，它會陸續幫你：

1. **認識你**：問你是做什麼的、最想讓 AI 幫什麼忙，寫成它的「員工手冊」
2. **裝上安全防護**：把最危險的指令列入黑名單、打開檔案存檔點（改壞了救得回來）
3. **接上外部工具**：操作瀏覽器、讀網頁
4. **裝適合你的技能模組**：文書處理（Word／PPT／Excel／PDF）人人都裝；
   醫療文獻、網頁簡報、社群文案——依你的工作挑
5. **帶你做幾個小測試**，並交給你一份**使用手冊（GUIDE.md）**——
   你會什麼功能、例句照抄、怎麼把它調教得越來越懂你
6. **選配**：接上 Gmail 與 Google 行事曆、設定第二位 AI（Codex）互審——要不要都由你決定

過程中會重開 app 一兩次——**重開後從左側清單點回原本那個對話**，
跟它說「繼續設定」，它就會接著做。

## 之後平常怎麼用

每次要用：打開 Claude app → **Code** 分頁 → 開始交代事情。
完整的功能地圖與例句在 **[GUIDE.md](GUIDE.md)**（設定時 Claude 會放一份到你的工作資料夾）；
忘記什麼，跟它說「**打開使用手冊**」就好。

| 你想做的事 | 怎麼做 |
|---|---|
| 交代任務 | 在輸入框用日常語言打字，像跟助理說話 |
| 回到之前的對話 | 左側清單直接點那個對話 |
| 對話太長、變慢了 | 輸入 `/compact` 幫對話瘦身 |
| 換一個全新話題 | 開一個新對話（或輸入 `/clear`） |
| 看有哪些指令 | 輸入 `/help` |
| 它做到一半你想喊停 | 按 `Esc` |

**新手心法：**

- 描述「你要的結果」就好，不用管步驟。
  例：「幫我把這份 PDF 的重點整理成一頁 Word。」
- 它主要看得到你選的那個**工作資料夾**；要處理其他位置（例如桌面）的檔案，
  它會再跳視窗問你允不允許——所以把要處理的檔案放進工作資料夾最順。
- 做錯了就叫它改，它不會覺得煩；**重要檔案動工前先說「先備份一份再改」**——
  有備份才保證救得回來。
- 不知道怎麼開口，就先問：「我想做◯◯，你會建議怎麼做？」

## 怪怪的時候（小故障表）

| 症狀 | 先試這個 |
|---|---|
| 某個工具突然不能用 | 輸入 `/mcp` 看狀態；不行就完全關掉 app 再開 |
| 它做到一半停住很久 | 按 `Esc` 喊停，請它「從剛剛中斷的地方繼續」 |
| 出現看不懂的錯誤訊息 | 整段複製貼給它，問「這是什麼意思、怎麼辦」 |
| 越用越慢 | `/compact`；再不行就開新對話 |

要找人求助時，把「你想做什麼＋它說了什麼（錯誤訊息全文）」一起附上，
最省來回；**畫面裡有病人或客戶資料的截圖不要傳**。

## 還能更進一步（都是選配，設定時 AI 會問你要不要）

- **信箱與行事曆**：接上 Gmail 和 Google 日曆後，可以直接問
  「我明天有什麼行程？」「找◯◯寄來的那封信」「幫我加一個下週二的會議」。
  設定超簡單：點兩下選單、用 Google 帳號登入授權就好，AI 會帶著你。
- **第二位 AI 互審（Codex）**：如果你也有訂閱 ChatGPT，可以加裝 OpenAI 的
  Codex 當「第二意見」——重要的東西做完，讓兩家公司的 AI 互相挑錯再交出去。

- **雙棲（兩個 AI 一起用）**：已經有一個、想加另一個？或想讓兩邊共用同一份員工手冊與技能、
  做完重要的東西互相審稿？看 [DUAL.md](DUAL.md)，AI 也能照著幫你設。

當下跳過了也沒關係，之後隨時跟 AI 說「我想接行事曆」「我想裝另一個 AI」就能補裝。

## 想用終端機版？（進階，可跳過）

Claude Code 也有純文字的「終端機版」，適合之後想玩自動化排程的人。

- **Mac**：打開「終端機」（Cmd＋空白鍵搜尋 Terminal），貼：
  ```
  curl -fsSL https://claude.ai/install.sh | bash
  ```
- **Windows**：打開「PowerShell」（開始選單搜尋），貼：
  ```
  irm https://claude.ai/install.ps1 | iex
  ```

裝完重開終端機、輸入 `claude` 登入即可。
桌面版與終端機版**共用同一套設定與技能**，兩邊可以並用、互不干擾。

## 一件值得知道的事（工作上會經手病患或客戶資料的人，看一眼就好）

你給 Claude 看的內容（打字、貼圖、請它讀的檔案）都會傳到雲端處理——
「檔案放在自己電腦裡」不等於「資料不會出去」。
所以會經手病患或客戶個資的人，養成一個習慣就好：
**能識別出某個人的資料，先把姓名等可辨識資訊拿掉，再給它。**
設定時會依你的行業把這個習慣記進個人設定檔，之後 Claude 會幫你留意——
其他就照常用，不用緊張。
