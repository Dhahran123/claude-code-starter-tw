# Claude Code 新手入門包（Mac 版）

給第一次接觸 AI 工具的你。這份指南會帶你在 Mac 上裝好 Claude Code，
然後——這是最棒的部分——**讓 AI 自己幫你完成剩下的所有設定**。

---

## Claude Code 是什麼？

你可能用過 ChatGPT：像一位「用訊息聊天的顧問」，你問它答。

Claude Code 不一樣，它像**坐在你電腦前的助理**：你用日常語言交代事情，
它可以直接幫你讀寫檔案、整理資料夾、上網查資料、做簡報、查醫學文獻。
全程不需要會寫程式。

## 你需要準備

- 一台 Mac（macOS 13 以上）
- **Claude 付費帳號**：到 [claude.ai](https://claude.ai) 註冊並訂閱 Pro（約 US$20／月）或 Max。
  免費帳號不能用 Claude Code。
- 大約 30–60 分鐘

---

## 第 1 步：打開「終端機」

按 `Cmd + 空白鍵` → 輸入 `終端機`（或 `Terminal`）→ 按 Enter。

終端機就是「用文字跟電腦下指令的視窗」。看起來很工程師，
但接下來你只需要**複製、貼上、按 Enter**。

## 第 2 步：安裝 Claude Code

把下面整行複製貼進終端機，按 Enter：

```
curl -fsSL https://claude.ai/install.sh | bash
```

跑完後，關掉終端機再重新打開一次，輸入：

```
claude --version
```

有跳出版本號就代表裝好了。

## 第 3 步：第一次啟動與登入

先建一個工作資料夾（以後 Claude 都在這裡幫你做事），然後啟動它。
把下面整行貼進終端機：

```
mkdir -p ~/claude-work && cd ~/claude-work && claude
```

第一次啟動會問幾個問題（配色之類的，按 Enter 用預設就好），
然後會打開瀏覽器要你登入 Claude 帳號。登入完成回到終端機，
看到可以打字的輸入框就成功了。

## 第 4 步：把剩下的設定交給 AI（魔法咒語）

把下面這**整段**複製，貼進 Claude Code 的輸入框，按 Enter：

```
請先讀取這個網址的設定指南：
https://raw.githubusercontent.com/Dhahran123/claude-code-starter-tw/main/SETUP.md
讀完之後，照著裡面的指示一步一步帶我完成所有設定。
我是完全新手、不是工程師，請全程用白話的繁體中文，
每一步先告訴我會發生什麼事再動手。
```

Claude 動手前都會先徵求你的同意（畫面會跳出「要不要允許」）。
看得懂就允許；看不懂就先問它「這一步在做什麼？」——它會解釋，不會不耐煩。

接下來大約 20–40 分鐘，它會陸續幫你：

1. **建立你的個人設定檔**（它會先訪問你幾個問題，把你的偏好寫成它的「員工手冊」）
2. **接上外部工具**：操作瀏覽器、讀網頁、查 PubMed 醫學文獻資料庫
3. **安裝技能包**：文書處理（Word／PPT／Excel／PDF）、牙科文獻評讀、網頁簡報
4. **帶你做幾個小測試**，教你日常怎麼用

## 之後平常怎麼用

每次要用：打開終端機 → 貼 `cd ~/claude-work && claude` → 開始交代事情。

| 你想做的事 | 怎麼做 |
|---|---|
| 交代任務 | 直接用日常語言打字，像跟助理說話 |
| 回到上次的對話 | 輸入 `/resume` 選一個 |
| 對話太長、變慢了 | 輸入 `/compact` 幫對話瘦身 |
| 換一個全新話題 | 輸入 `/clear` |
| 看有哪些指令 | 輸入 `/help` |
| 它做到一半你想喊停 | 按 `Esc` |
| 覺得哪裡怪怪的 | 輸入 `/doctor` 自我診斷 |

**新手心法：**

- 描述「你要的結果」就好，不用管步驟。
  例：「幫我把桌面那份 PDF 的重點整理成一頁 Word。」
- 它看得到你電腦裡的檔案（你允許的範圍內），所以可以直接說「桌面那個資料夾」。
- 做錯了就叫它改，檔案改壞了就叫它還原，它不會覺得煩。
- 不知道怎麼開口，就先問：「我想做◯◯，你會建議怎麼做？」

## ⚠️ 給醫療人員的重要提醒

**病人的個資——姓名、病歷、口內照、X 光、約診資料——不要餵給任何雲端服務。**

Claude Code 在「你自己的電腦裡」讀寫檔案沒有問題；
但只要牽涉「傳出去」（上傳到生圖網站、公開發布、外部表單），
就必須先**去識別化**：拿掉姓名與所有可辨識資訊。

設定過程會把這條紅線寫進你的個人設定檔，之後 Claude 會自動幫你把關——
但最後一道防線永遠是你自己。
