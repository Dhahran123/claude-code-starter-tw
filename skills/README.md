# 自帶技能資料夾

這裡放整理者自製、直接分享給使用者的技能包。
每個技能一個資料夾，裡面至少有 `SKILL.md`；`SETUP.md` 的階段 3e 會自動安裝這裡的技能。

## 目前內容

- **dental-lit** — 牙科文獻檢索與驗貨管線（分享版）。
  臨床問題→PICO→PubMed/OpenAlex 雙軌搜→撤稿/來源/定位三層驗貨→證據表。
  每筆引用都當場實際解析過才交付，不憑記憶給文獻。
  需要 SETUP.md 階段 2 裝的 pubmed 與 openalex 工具。
  與 3b 牙科文獻評讀 5 支是搭配關係：本技能負責「找到並驗證文獻」，那 5 支負責「深入評讀」。
